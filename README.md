# Calculadora de Cuota de Préstamo

Práctica de Backend - Estructuras de Datos y Algoritmos 1
Universidad Autónoma de Occidente

## Descripción

Aplicativo web backend desarrollado en Node.js y Express que calcula la cuota mensual fija que debe pagar una persona por un préstamo, dado el monto, el número de meses (n) y la tasa de interés (i).

Fórmula utilizada (amortización francesa): cuota = P * i / (1 - (1 + i)^(-n))
